Automation proof - runs the pipeline every day at 2:00 AM.

   crontab -e

2. Add this line (adjust the path to wherever the repo actually lives):
   0 2 * * * cd /home/paul/week4_etl_pipeline && /usr/bin/python3 run_pipeline.py >> automation/cron_output.log 2>&1

   crontab -l
